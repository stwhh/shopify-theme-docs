Search & social media

Search & social media

Search

Setting Description
Search suggestions Comma-separated popular terms in the search dropdown
Predictive search Live product/page results as the shopper types

Example suggestions: Serum, Moisturizer, SPF, Lipstick

Predictive search uses Shopify Search — ensure products are published and searchable.

Social media

For each network:

  1. Enable the toggle.
  2. Paste the full profile URL (e.g. https://instagram.com/yourbrand).
  3. Set the Follow us heading — shown in mobile menu and footer.

Disabled networks are hidden automatically. URLs are also used for footer social icons when Show social icons is enabled in the Footer section.
