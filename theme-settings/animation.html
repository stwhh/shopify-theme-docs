Animation

Animation

Theme settings → Animation controls movement and visual effects across your storefront.

Settings

Enable scroll animations

When turned on, sections fade and slide into view as customers scroll down the page. Headings appear first, followed by product cards and images in a staggered sequence. This creates a polished, editorial feel similar to premium brand websites.

When turned off, all content appears immediately with no entrance effects — cleaner for stores that prefer a static layout.

Default: On

Stagger delay

Controls the timing gap between each card or item appearing in sequence. A lower number creates a faster, tighter cascade. A higher number slows the reveal for a more dramatic, drawn-out entrance.

Setting Effect
0 ms All items appear simultaneously
80 ms (default) Subtle ripple — items appear one after another
200 ms Slow, dramatic reveal — each item clearly separates

Animation speed

Sets how quickly elements complete their entrance animation.

Speed Duration Best for
Slow ~1 second Luxury, high-end — emphasis on each element
Medium (default) ~0.7 seconds Balanced — noticeable but not distracting
Fast ~0.4 seconds Energetic, fast-paced — quick browsing

Show quick-add on hover

When enabled on desktop, product card buttons (Add to cart, Choose options, Sold out) are hidden by default and slide into view when the customer hovers over a product card. This creates a cleaner, less cluttered grid while keeping purchasing actions accessible.

On mobile, buttons remain always visible since hover is not available.

Default: Off (buttons always visible)

Accessibility

All animations respect your customers' operating system accessibility settings. If a customer has Reduce motion enabled (Mac: Accessibility → Display, Windows: Accessibility → Visual effects), all scroll animations and shimmer effects are automatically disabled. No extra setup required.

Dark mode

Your theme's color scheme setting is under Theme settings → Layout → Color scheme, with three options:

Option Behavior
Light only Always light background
System preference (default) Follows the customer's OS dark mode setting
Dark only Always dark background

When dark mode is active, the theme uses a warm dark palette (#171a17 background) designed specifically for beauty and skincare brands, ensuring product imagery remains the focal point.
