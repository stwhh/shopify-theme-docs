Announcement bar & header

Announcement bar & header

Both live in the Header group (edit from any page via the header group link in the sidebar).

Announcement bar

Feature Details
Multiple blocks Add several announcement messages
Links Optional URL per message
Rotation Desktop arrows cycle through messages

Example uses: Free shipping threshold, sale dates, new collection launch.

Header settings

Setting Description
Menu Shopify Navigation menu. Cleared = no menu links (Navigation item blocks still work). Renders on desktop and mobile, up to three levels.
Country selector Flag + country; auto-applies on selection
Language selector Lists published store languages
Section colors Optional custom header background/text

Built-in header features

  • Logo or shop name (links home)
  • Desktop navigation
  • Mobile drawer menu
  • Predictive search
  • Account link (when customer accounts enabled)
  • Cart icon → opens cart drawer
  • Localization + social in mobile drawer

Nav item blocks (mega-menu style)

Add Nav item blocks for rich navigation alongside or instead of the link list menu:

Block field Purpose
Title Top-level label
Link Optional URL when clicking the title
Image Featured image in dropdown
Submenu links Nested links per block

Use Nav items for campaign imagery (e.g. “Skincare” with a hero photo and sub-collection links).
