Localization

Localization

Enable country and language selectors in the Header section.

Setting Requirement
Country selector Settings → Markets — multiple countries/regions
Language selector Settings → Languages — multiple published languages

Behavior

  • Flag + label in dropdown
  • Choosing an option applies immediately (no Update button)

Translate theme strings

Settings → Languages → Translate → Online Store → Sheer

Enable multiple languages or countries

  1. Languages: Settings → Languages — add languages and translate content.
  2. Markets: Settings → Markets — configure countries/regions.
  3. Theme: Header → enable Country selector and/or Language selector.
