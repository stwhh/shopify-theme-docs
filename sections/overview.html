Overview

Homepage sections overview

Default homepage order:

Hero video → Brand values → Product card → Collection tabs → Ingredient highlights → Before / after → Routine builder → Shade finder → Beauty collage → Promo banner → Stock counter

You can add, remove, reorder, or duplicate any section in the theme editor.

Section index

Section Purpose
Hero video Full-bleed video and/or image carousel
Product card Grid or carousel from one collection
Collection tabs Tabbed product rows per collection
Promo banner Full-width campaign strip
Beauty collage Editorial masonry product grid
Before / after Drag-to-compare imagery
Brand values Icon trust grid
Featured product Single product highlight
Other sections Rich text, newsletter, recommendations, FAQ

Adding a new homepage section

  1. Open Homepage in the theme editor.
  2. Click Add section.
  3. Choose a section (e.g. Beauty collage, Rich text).
  4. Configure settings and blocks → Save.
