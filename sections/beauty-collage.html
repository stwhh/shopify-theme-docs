Beauty collage

Beauty collage

Editorial masonry or uniform grid for campaign storytelling.

Mode A — Collection only (automatic)

Best for pulling products from a collection with minimal setup:

  1. Open Beauty collage section settings.
  2. Select a Collection.
  3. Set Products to show (6–90, default 18, step 3).
  4. Remove all Product tile blocks (if any exist).
  5. Save.

Sheer shows each product’s featured image, title, price, truncated description, and link. Second product image is used for hover when available.

Mode B — Manual Product tile blocks

Best for curated campaigns with custom copy and imagery:

  1. Add Product tile blocks (one per tile).
  2. Configure each block:
Block field Notes
Product Optional — fills image, title, price, URL
Image Primary packshot
Hover image Lifestyle / on-model shot
Title / Description Custom copy
Price label Manual text when no product (e.g. From $38)
Link Custom URL
  1. Optionally set section Collection — empty product fields pull from this collection in order.

Layout settings

Setting Description
Desktop layout Masonry editorial or uniform 4:5 grid
Columns 3 or 4 on desktop
Tile spacing Vertical and horizontal gaps
Swipe on mobile Horizontal scroll (uniform layout)
Show description / price Toggle metadata

Troubleshooting

Issue Fix
Empty collage (collection mode) Select collection, set Products to show, remove Product tile blocks
Empty collage (manual mode) Add blocks or set fallback collection
