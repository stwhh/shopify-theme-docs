Hero video

Hero video

Full-bleed first impression with video and/or image carousel.

Section settings

Setting Description
Media mode Video only · Carousel only · Video + carousel
Video Upload via Shopify video picker
Video URL YouTube or Vimeo link
Cover image Poster/fallback when video does not load
Enable video looping Loop embed video
Enable parallax Subtle scroll movement
Heading / Text / Button Overlay on standalone video mode
Height Desktop and mobile hero height

Slide blocks (carousel)

Field Purpose
Image Full-width slide background
Show caption Eyebrow + heading on slide
Eyebrow Small label (e.g. “New in”)
Heading / Text Main copy
Button label / link CTA to collection or page

Tips

  • Use Carousel only for image-only campaigns.
  • First slide loads with high priority — use your strongest visual there.
  • Keep headline text short; it overlays the image.
  • Mobile browsers may require muted video — the theme mutes by default.
