Collection & search

Collection page

Feature Configuration
Banner image Show collection image in Collection section
Products per page Collection section setting
Sort by Shopify default sort options
Filters Search & discovery (see Faceted search)
Grid spacing Theme settings → Layout

Filter UX: Filter opens left drawer → select → Apply. Active filters show as pills; remove individually or use the Clear all button.

Search page

Same toolbar and filter drawer as collections. Results include products and pages.

Header predictive search: Theme settings → Search.

Collections list (/collections)

Collections grid section:

Setting Description
Collections per page 6–48
Grid item width Small or large cards

Each card shows image, title, description excerpt, and product count.
