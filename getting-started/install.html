Install & publish

Install & publish

Install the theme

  1. In Shopify admin, go to Online Store → Themes.
  2. Click Add theme:
    • Upload zip file — if you received Sheer as a .zip
    • Or install from the Theme Store when published
  3. Click Customize on Sheer to open the theme editor.
  4. When ready, click Publish to make Sheer your live storefront theme.

Tip: Before major changes, use Duplicate on your theme in Online Store → Themes so you always have a backup.

Recommended first steps

# Task Where
1 Upload logo and favicon Theme settings → Logo
2 Set brand colors Theme settings → Colors
3 Choose primary font Theme settings → Typography
4 Configure header menu Header section
5 Add social profile URLs Theme settings → Social media
6 Set up Search & discovery filters Shopify admin → Search & discovery
7 Review homepage sections Theme editor → Homepage
8 Customize product page blocks Theme editor → Product page
9 Test Add to cart → cart drawer → checkout Storefront

Update the theme

When a new version of Sheer is released:

  1. Duplicate your current theme (backup).
  2. Upload or install the new version.
  3. Compare Theme settings and section settings against your backup.
  4. Publish when satisfied.

Keep a backup before updating — settings do not always merge automatically between versions.
