Faceted search

Faceted search

Sheer displays filters configured in Shopify admin — the theme does not hard-code filter types.

Setup

  1. Shopify admin → Search & discovery
  2. Click Filters
  3. Add filter:
Filter type Beauty example
Availability In stock / out of stock
Price Price ranges
Product type Skincare, Makeup, Tools
Vendor Brand filters
Variant option Color, Size, Finish
Metafield Skin type, concern
  1. Save
  2. Preview collection and search pages on the storefront

Filter UX

  • Filter button opens left drawer
  • Active filters show as pills above the grid
  • Remove one pill, or use the Clear all button (toolbar + drawer footer)
  • Drawer footer: Clear all (secondary) + Apply (primary)
  • Apply closes drawer on mobile

Filters not showing?

Add filters in Search & discovery, not the theme editor.

Swatch filters

Keep variant option names consistent (e.g. always “Color”) so swatch filters work across the catalog.
